# Referencias visuales de Ara gossei

## Boceto del proyecto

- Archivo: `references/species/ara_gossei_images/00_boceto_usuario_ara_gossei.png`
- Procedencia: boceto aportado para este proyecto.
- Uso: referencia de composición ambiental; muestra las Blue Mountains de
  Jamaica, palmera, rama y disposición vertical de la lámina.
- No es una fuente zoológica independiente: los rasgos de la especie deben
  contrastarse con las fuentes históricas y taxonómicas.

Descargadas desde Wikimedia Commons para estudiar forma, color y ambiente. No forman parte automáticamente de la ilustración final.
